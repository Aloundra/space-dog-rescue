# Space Dog Rescue

A tribute to the Flash shoot'em up **Iron Chouquette** (kadokado.com), renamed **Space Dog Rescue**: pilot your ship and rescue your dog, kidnapped by enemy spaceships.

TypeScript + Canvas 2D + Vite. No game library, no image or sound files: all the pixel art is generated by the code.

## Running

```bash
npm install
npm run dev        # http://localhost:5280
npm run build      # typecheck + production build into dist/
npm run preview    # serves dist/
npm test           # unit tests + headless simulation of a full run
```

## Playing

| Key | Action |
|---|---|
| Arrows | Move the ship |
| Space | Fire (hold) |
| Ctrl or Shift | Sacrifice the most recent weapon → devastating salvo (1 press = 1 sacrifice) |
| Esc / P | Pause (Q while paused: back to menu) |
| Enter | Confirm in menus |

- **Health bar: 3 HP**, no lives. At 0 HP, the game is over.
- Destroy the ships shaped like a **gamepad** (neutral grey) to release a surprise weapon.
- **5 weapons maximum** (each boss drops a "+1 slot", up to 8). Beyond that, the oldest weapon is sacrificed automatically (and triggers its salvo).
- Several copies of the same weapon = a more powerful weapon (max level 4).

| Weapon | Effect |
|---|---|
| Violet | Small violet balls in all directions (more of them, and farther, with each level) |
| Pink | Speeds up the ship |
| Green | Improves the base weapon (fire rate, number of shots, damage) |
| Yellow | Fires on both sides at once (then diagonals, then rear) |
| Blue | Missiles (homing from level 2) |
| Red | Electric beam laser |

4 levels, with a boss at the end of each; the last one holds your dog. Top 10 scores saved in the browser (`localStorage`).

### Development options (URL)

`?level=3` (starting level), `?boss` (go straight to the boss), `?god` (invincible), `?weapons=red,blue,green`.
Example: `http://localhost:5280/?level=4&boss&god&weapons=red,red,green`.
In dev mode, the application is accessible from the console via `window.__app`.

## Architecture

```
src/
  config.ts          constants (resolution 800×1000, play area, HP…)
  core/              fixed-step 60 Hz loop, keyboard, scaling, PRNG
  data/              catalogs: enemies (exact points), weapons, levels/waves/bosses
  game/              DOM-free logic: World, FIFO inventory, enemy AI, boss, spawner, score
  render/            pixel-art sprites (matrices + procedural generators), nebula, HUD, rendering
  ui/                screen state machine, high scores
tests/               Vitest (pure logic + full-run simulations)
```

Design choices not specified by the brief are listed in [PLAN.md](PLAN.md).

## Local deployment (LAN)

The game is served continuously at **http://127.0.0.1:5280** by a systemd user service
(`deploy/space-dog-rescue.service`, installed in `~/.config/systemd/user/`). On startup, it rebuilds and then runs `vite preview` on `0.0.0.0:5280`.

```bash
systemctl --user restart space-dog-rescue   # after a code change
systemctl --user status space-dog-rescue
systemctl --user disable --now space-dog-rescue   # stop permanently
```
Note: `npm run dev` uses the same port; stop the service before starting the dev server.
